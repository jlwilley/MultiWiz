# MultiWiz
This is a Wizard 101 login and account manager. Currently this application can allow for quickly logging in multiple wizard101 applications. After logging in, it allows quickly switching between active windows for more easy wizard management. Currently this application only runs on Windows. If Wizard101 updates you must relaunch using the official launcher before using multiwiz

## Download Instructions
Select the latest release on the right side of the page.


From there download MultiWiz.zip
Extract to the multi wiz folder and run Multiwiz.exe.
If you want a desktop shortcut just right click MultiWiz.exe and create shortcut.
![DownloadLocation](https://github.com/jlwilley/MultiWiz/assets/83674331/a06b8b9d-110c-410f-988a-ce2ae170ee08)

## Usage Instructions
Select add account to enter the add account dialog box.
Account name will be the name of the account seen when switching, this can be named anything and is not relevant to account info.
Username is the username of the account.
Password is the password of the account.
After adding the account it will be selectable from the list and you can easily open the game client by pressing open
When that game screen has been open for 5 seconds the game will automatically be logged in. Try to not click around too much while your games are logging in as it can cause issues.
You can select multiple accounts from the list at once for opening or closing by control clicking the entries.

After your accounts are open you can click the switcher button to pull up a quick switcher menu that sits at the right of your screen. This menu allows you to quickly swap between versions of the game that you are controlling.
